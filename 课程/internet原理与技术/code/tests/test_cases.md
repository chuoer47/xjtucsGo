# 测试用例

1. 小文件下载
- 输入文件：`tests/data/small.txt`（1KB）
- 期望：客户端输出与原文件一致。

2. 中等文件下载
- 输入文件：`tests/data/medium.bin`（1MB）
- 期望：客户端输出与原文件一致。

3. 大文件下载
- 输入文件：`tests/data/large.bin`（25MB 以上）
- 期望：客户端输出与原文件一致，传输过程中无断开。

4. 文件不存在
- 请求不存在文件名
- 期望：客户端提示服务器错误并退出。

5. 小文件上传
- 输入文件：`tests/data/small.txt`（1KB）
- 期望：服务端生成上传文件，内容一致。

6. 中等文件上传
- 输入文件：`tests/data/medium.bin`（1MB）
- 期望：服务端生成上传文件，内容一致。

7. 大文件上传
- 输入文件：`tests/data/large.bin`（25MB 以上）
- 期望：服务端生成上传文件，内容一致。

8. 上传本地文件不存在
- 本地路径不存在
- 期望：客户端直接报错并退出。

9. 上传目标已存在 / 权限不足
- 目标文件已存在或目录不可写
- 期望：服务端返回错误状态码，客户端提示失败并退出。

10. 报文验证
- 使用 Wireshark 抓包
- 期望：握手/挥手、序列号/ACK 符合 TCP 规则。

11. MSS 选项协商
- 操作：服务端设置 `mss=1200` 启动，客户端连接并下载小文件。
- 期望：SYN/SYN+ACK 中包含 MSS 选项；客户端输出的协商 MSS 接近 1200（或不超过 1200）。

12. Window Scale 选项协商
- 操作：服务端设置 `window_scale=8` 启动。
- 期望：SYN/SYN+ACK 中包含 Window Scale 选项；ACK 中窗口字段与扩大因子匹配（Wireshark 中可见实际窗口值）。

13. SACK 选项与重传优化
- 操作：开启 SACK（默认开启），使用 `tc netem` 制造轻微丢包/乱序后传输中等文件。
- 期望：ACK 报文包含 SACK 块；服务端重传仅针对未被 SACK 的段（Wireshark 可观察重传行为）。
