# 📚 XJTUCS 研究生资料整理仓库[持续更新...]

> 一个面向西安交通大学研究生课程作业、常用资料与实用工具的开源整理仓库 ✨

这个仓库主要用来沉淀三类内容：

- `课程`：课程作业、实验材料、报告、代码、复习资料
- `课外`：校内常用文件、经验整理、一些专题资料
- `实用工具`：平时可能会用到的小工具或辅助资源

## 🔍 建议查找方式

如果你是第一次打开这个仓库，建议按下面顺序找：

1. 先按大类进入：`课程 / 课外 / 实用工具`
2. 再按具体主题进入对应子目录
3. 优先阅读子目录下的 `README.md`
4. 课程内容优先看 `report.md`、`docs/`、`code/`
